📊 Bank Loan Analysis Dashboard 

This project presents an interactive Bank Loan Analysis Dashboard built using Microsoft Excel. The dashboard analyzes loan applications, funded amounts, repayment performance, and borrower characteristics to generate meaningful financial insights.

📁 Project Overview

The dataset contains information related to loan applications, funded amounts, loan repayments, interest rates, loan purposes, employment length, and home ownership. Using Excel features such as Pivot Tables, charts, and dashboard design, the data was analyzed and visualized to understand loan performance and trends.

📊 Key Metrics

The dashboard highlights important loan statistics:

Total Loan Applications: 38.6K

Total Funded Amount: $473.1M

Total Amount Received: $435.8M

Average Interest Rate: 12.05%

Average DTI: 13.33%

📈 Dashboard Analysis

The dashboard provides multiple insights including:

Loan Applications by Month – Monthly trend of loan requests.

Loan Applications by State – Geographic distribution of loan applications.

Loan Applications by Term – Comparison of loan duration categories.

Loan Applications by Purpose – Reasons customers apply for loans.

Loan Applications by Employment Length – Relationship between employment stability and loans.

Loan Applications by Home Ownership – Loan distribution based on housing status.

The analysis also categorizes loans into Good Loans (86.18%) and Bad Loans (13.82%), helping understand loan performance and potential risk.
